# Table artwork

The lounge background and two female dealer portraits are original AI-generated artwork created for Teen Patti Companion. They do not use artwork, logos, or characters from another game.

- `lounge.png`: private card lounge background.
- `dealer-anaya.png`: Anaya, emerald waistcoat.
- `dealer-tara.png`: Tara, burgundy sari.

Dealer portraits preserve their generated transparent backgrounds. They are decorative character choices; the server continues to deal all cards.

Standing dealer variants (`dealer-anaya-standing.png`, `dealer-tara-standing.png`) were created with the built-in image-generation tool from the original character portraits. Prompt: preserve each adult female character, clothing and warm lighting; change to a centered front-facing standing pose with outstretched arms and palms resting on the rail, and export a transparent cutout without a table, backdrop, text or branding. The supplied gameplay screenshots informed only the pose and framing.
